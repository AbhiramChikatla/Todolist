# To-Do List Application

## Overview
This is a simple and user-friendly To-Do List application that allows users to manage tasks efficiently. The application helps users create, track, and manage their daily tasks with ease.

## Features
- Add new tasks with a title and description.
- Edit or update existing tasks.
- Mark tasks as completed.
- Delete tasks that are no longer needed.
- Simple and intuitive user interface.
- Data persistence (tasks are saved locally).


## Usage
1. Open the app in your browser.
2. Add tasks using the 'Add Task' button.
3. Mark tasks as completed when done.
4. Filter tasks to view pending or completed tasks.

## Technologies Used
- HTML, CSS, JavaScript (Frontend)
- LocalStorage (Data Persistence)
